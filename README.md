🌤️ Weather App

A simple and beautiful weather application that allows users to check real-time weather details by entering any city, ZIP code, or coordinates.
This app uses the WeatherAPI.com service to fetch temperature, humidity, wind speed, air quality, and more.

🚀 Features

🌎 Search weather by city, ZIP code, or latitude/longitude

🌡️ Shows temperature in °C and °F

🌬️ Displays humidity, pressure, wind speed

🍃 Includes AQI (PM2.5) air quality

📍 Auto-detects user location (if permission granted)

🖥️ Clean and modern UI

⚡ Fast API response

📦 Installation

Clone the repo:

git clone https://github.com/MOHDUBES/Weather-App.git


Open the project folder:

cd Weather-App


Open index.html in any browser.

🔑 API Key

This app uses WeatherAPI:

https://api.weatherapi.com/v1/current.json


You can replace the key inside app.js:

const API_KEY = "YOUR_API_KEY";

📝 Usage

Type a location (city, ZIP code, or coordinates)

Click Get weather

The app will instantly show weather details

📌 Note

This demo uses a visible API key.
For production, always keep your API keys hidden using a backend server or proxy.
